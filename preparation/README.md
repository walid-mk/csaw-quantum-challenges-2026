# Participant preparation

Welcome to the CSAW 2026 Quantum Security Challenge (QSec). These short materials
help you arrive ready to work with your team:

- [QAML background and setup](qaml/README.md): essential concepts and a small,
  generic software check. It contains no challenge tasks, solutions or scoring details.
- [Five-minute technical presentation guide](presentation-guide.md): a suggested
  structure that works for any of the event's technical challenges.

Check Discord `#announcements` and `#schedule` for confirmed event instructions.
Challenge day is **Friday, 13 November 2026**: MENA follows GST and US/Canada
follows ET. Exact times are published in the [event schedule](../docs/schedule.md).
